# RoleElementPicker V1 产品需求

## 一、产品定位

自动化测试脚本录制工具：测试人员在网页上点击元素，工具自动识别元素属性，生成 Java Page Object Model 代码（页面类 + 步骤类 + 断言类），减少手写定位器的工作量。

---

## 二、使用场景

测试用例执行到某个页面时，调用一行代码启动录制工具：

```java
RoleElementPicker.openPanel(page, "login_page.properties");
```

工具弹出独立窗口，测试人员在浏览器上操作页面，把需要的元素"点"进工具，停止后自动生成 Page Object 代码。

---

## 三、核心功能需求

### 3.1 元素拾取

- 在网页上 hover 元素时，元素高亮显示
- 点击元素即拾取该元素，拾取后出现在工具窗口的列表中
- 同一个元素重复点击不重复添加，更新拾取序号
- 拾取时自动识别：元素 role、可见名称、定位方式（id/testid/text/css 等）
- 跨 iframe / 弹窗 / 新标签页内的元素也能拾取
- 拾取过程中页面正常运行，不冻结 JS（动画、弹窗、轮询都在）

### 3.2 录制控制

- **开始拾取**：进入拾取模式，页面元素可被高亮和点击
- **停止拾取**：退出拾取模式，根据当前已拾元素生成代码
- **关闭**：结束录制，测试继续往下执行
- 一次开始→停止 = 一个步骤（Step），支持多次开始→停止形成多个步骤

### 3.3 已拾元素列表

- 实时显示已拾取的元素列表，包含：序号、role、名称、定位方式
- 支持删除已拾取元素
- 支持标记某元素为"列表元素"（生成 PageElementList 而非单个字段）
- 跨多个页面/弹窗拾取的元素按页面分组

### 3.4 代码生成

停止拾取后，自动生成三类代码并在工具窗口中展示：

- **页面类**：每个拾取元素生成一个 `@RoleElement` 注解字段
- **步骤类**：按拾取顺序生成步骤方法，包含 click/fill 等操作
- **断言类**：对拾取的元素生成断言代码

- 支持复制生成的代码
- 支持 i18n：如果元素名称匹配 nls 资源文件，自动用 `i18n:xxx` 定位符

### 3.5 弹窗与导航

- 操作过程中弹出新窗口/新标签页，工具自动跟随，新页面里拾取的元素归到对应页面类
- 页面内跳转后，拾取工具自动继续工作
- 关闭弹窗后，自动回到父页面继续拾取

---

## 四、非功能需求

### 4.1 CI 环境

- 在 CI/Jenkins 环境下自动跳过录制，不阻塞构建
- 录制功能只在本地开发时使用

### 4.2 不干扰被测页面

- 录制工具的窗口是独立的，不在被测网页上注入面板
- 被测页面的 DOM 不被录制工具污染

### 4.3 性能

- 点击元素到列表显示在 500ms 内
- 生成代码在停止后 1 秒内显示

---

## 五、不做的事（V1 排除）

- 不做单步调试（那是 page.pause() 的事）
- 不做网络请求录制（有独立 API Monitor）
- 不做多语言代码输出（只生成 Java）
- 不做自动等待策略录制（框架已有）
- 不做 AI 自动分组/智能清洗
